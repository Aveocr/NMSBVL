# Метод сеток для решения краевой задачи

## Задание 

Решить численно на отрезке [1, 2] *методом сеток* $x^2 y'' + xy' - 16y = -16 \ln{x}$ при заданных граничных условиях $y(1) = 1$; $y'(2) -y(2) = 15.806 и числе
разбиений 8. Сравнить приближенные решения $y = x^4 + \ln{x}$ с точным решением, построив
соответствующие графики. Оценить погрешность численных решений.


## Теория

### Метод сеток

Метод сеток (или метод конечных разностей) - это численный метод решения дифференциальных уравнений, который заключается в замене производных разностными отношениями.

#### Шаги метода:

1. **Дискретизация** - разбиваем отрезок [a, b] = [1, 2] на n равных частей с шагом h = (b-a)/n
2. **Аппроксимация производных** - заменяем производные на их конечно-разностные аналоги
3. **Построение СЛАУ** - формируем систему линейных алгебраических уравнений
4. **Решение СЛАУ** - находим значения искомой функции в узлах сетки

#### Разностные схемы для производных:

Для аппроксимации первой и второй производных используются следующие формулы:

1. **Первая производная** (центральная разность):
   $$y'(x_i) \approx \frac{y_{i+1} - y_{i-1}}{2h}$$

2. **Вторая производная**:
   $$y''(x_i) \approx \frac{y_{i+1} - 2y_i + y_{i-1}}{h^2}$$

3. **Первая производная** (односторонняя разность вперед, используется для граничного условия):
   $$y'(x_i) \approx \frac{y_{i+1} - y_i}{h}$$

#### Построение разностной схемы:

Подставляя разностные аналоги производных в исходное уравнение:

$$x_i^2 \frac{y_{i+1} - 2y_i + y_{i-1}}{h^2} + x_i \frac{y_{i+1} - y_{i-1}}{2h} - 16y_i = -16 \ln{x_i}$$

Приводя подобные, получаем:

$$\left(\frac{x_i^2}{h^2} - \frac{x_i}{2h}\right) y_{i-1} + \left(-\frac{2x_i^2}{h^2} - 16\right) y_i + \left(\frac{x_i^2}{h^2} + \frac{x_i}{2h}\right) y_{i+1} = -16 \ln{x_i}$$

#### Учет граничных условий:

1. **Левое граничное условие** $y(1) = 1$:
   Данное условие напрямую задает значение $y_0 = 1$

2. **Правое граничное условие** $y'(2) - y(2) = 15.806$:
   Используя одностороннюю разность для аппроксимации производной:
   $$\frac{y_n - y_{n-1}}{h} - y_n = 15.806$$
   что дает:
   $$-\frac{1}{h} y_{n-1} + \left(\frac{1}{h} - 1\right) y_n = 15.806$$

### Оценка погрешности

Для оценки погрешности численного решения используются:

1. **Абсолютная погрешность**:
   $$\varepsilon_{abs} = |y_{exact} - y_{numerical}|$$

2. **Относительная погрешность**:
   $$\varepsilon_{rel} = \frac{|y_{exact} - y_{numerical}|}{|y_{exact}|} \cdot 100\%$$

## Реализация

Реализация метода представлена в файле `differential_equation_solver.py`. 

### Основные компоненты кода:

1. Создание сетки и определение точного решения
2. Формирование СЛАУ с учетом граничных условий
3. Решение СЛАУ
4. Проверка выполнения граничных условий
5. Расчет погрешности (абсолютной и относительной)
6. Построение графиков для наглядного сравнения

### Запуск программы:

```bash
python differential_equation_solver.py
```

Результатом работы программы будут:
1. Таблица значений численного и точного решений в узлах сетки
2. Проверка выполнения граничных условий
3. Оценка максимальной абсолютной и относительной погрешности
4. Графики численного и точного решений, а также график погрешности
