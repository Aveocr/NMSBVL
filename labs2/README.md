# Метод коллокаций для решения краевой задачи

## Задание 

Решить численно на отрезке [1, 2] \textbf{методом коллокаций}  $x^2 y'' + xy' - 16y = -16 \ln{x}$ при заданных граничных условиях $y(1) = 1$; $y'(2) -y(2) = 15.806 и числе
разбиений 8. Сравнить приближенные решения $y = x^4 + \ln{x}$ с точным решением, построив
соответствующие графики. Оценить погрешность численных решений.

## Теория

### Постановка задачи

Рассматривается краевая задача для обыкновенного дифференциального уравнения второго порядка:

$$x^2 y'' + xy' - 16y = -16 \ln{x}$$

с граничными условиями:

$$y(1) = 1$$
$$y'(2) - y(2) = 15.806$$

Точное решение данной задачи имеет вид:

$$y(x) = x^4 + \ln{x}$$

### Метод коллокаций

Метод коллокаций — это проекционный метод решения дифференциальных уравнений, в котором приближенное решение ищется в виде линейной комбинации базисных функций, а коэффициенты определяются из условия точного удовлетворения уравнению в заданных точках (узлах коллокации).

#### Основные этапы метода:

1. **Выбор базиса** — задается система линейно независимых функций $\{\phi_0(x), \phi_1(x), \ldots, \phi_n(x)\}$
2. **Представление приближенного решения** в виде:
   $$y(x) \approx \sum_{k=0}^{n} c_k \phi_k(x)$$
3. **Выбор узлов коллокации** — $\{x_1, x_2, \ldots, x_m\}$ (обычно $m = n+1$)
4. **Составление системы уравнений** — требование, чтобы в узлах коллокации выполнялось исходное дифференциальное уравнение:
   $$L[y](x_i) = f(x_i), \quad i = 1, 2, \ldots, m-2$$
   где $L[y]$ — левая часть дифференциального уравнения
5. **Учет граничных условий** — добавление уравнений, соответствующих граничным условиям
6. **Решение системы уравнений** — определение коэффициентов $c_k$

#### Полиномиальный базис

В нашей реализации используется полиномиальный базис:
$$\phi_k(x) = x^k, \quad k = 0, 1, \ldots, n$$

Приближенное решение представляется в виде полинома:
$$y(x) \approx \sum_{k=0}^{n} c_k x^k$$

#### Вычисление производных

Для подстановки в дифференциальное уравнение необходимо вычислить производные аппроксимирующей функции:

1. **Первая производная**:
   $$y'(x) \approx \sum_{k=1}^{n} k c_k x^{k-1}$$

2. **Вторая производная**:
   $$y''(x) \approx \sum_{k=2}^{n} k(k-1) c_k x^{k-2}$$

#### Система уравнений метода коллокаций

Для нашей задачи система имеет вид:

1. **Граничное условие при $x = 1$**:
   $$\sum_{k=0}^{n} c_k \cdot 1^k = 1$$

2. **Уравнения коллокации в узлах $x_i$, $i = 1, \ldots, n-1$**:
   $$x_i^2 \sum_{k=2}^{n} k(k-1) c_k x_i^{k-2} + x_i \sum_{k=1}^{n} k c_k x_i^{k-1} - 16 \sum_{k=0}^{n} c_k x_i^k = -16 \ln{x_i}$$

3. **Граничное условие при $x = 2$**:
   $$\sum_{k=1}^{n} k c_k \cdot 2^{k-1} - \sum_{k=0}^{n} c_k \cdot 2^k = 15.806$$

### Отличия от метода сеток

Основные отличия метода коллокаций от метода сеток:

1. **Форма приближенного решения**:
   - В методе сеток решение находится только в узлах сетки
   - В методе коллокаций решение представляется аналитической функцией на всей области

2. **Непрерывность решения**:
   - Метод коллокаций даёт непрерывное решение, представленное аналитической формулой
   - Метод сеток требует дополнительной интерполяции для получения решения между узлами

3. **Точность**:
   - При одинаковом числе узлов метод коллокаций часто даёт более точное решение
   - Точность метода коллокаций сильно зависит от выбора базисных функций

### Оценка погрешности

Для оценки погрешности численного решения используются:

1. **Абсолютная погрешность**:
   $$\varepsilon_{abs} = |y_{exact} - y_{numerical}|$$

2. **Относительная погрешность**:
   $$\varepsilon_{rel} = \frac{|y_{exact} - y_{numerical}|}{|y_{exact}|} \cdot 100\%$$

## Реализация

Реализация метода представлена в файле `collocation_method_solver.py`.

### Основные компоненты кода:

1. Определение базисных функций и их производных
2. Формирование системы уравнений с учетом граничных условий
3. Решение системы нелинейных уравнений для определения коэффициентов
4. Построение аппроксимирующей функции
5. Оценка погрешности
6. Визуализация результатов

### Запуск программы:

```bash
python collocation_method_solver.py
```

Результатом работы программы будут:
1. Таблица значений приближенного и точного решений в выбранных точках
2. Проверка выполнения граничных условий
3. Оценка максимальной абсолютной и относительной погрешности
4. Полиномиальное представление приближенного решения
5. Графики приближенного и точного решений, а также график погрешности

## Интерпретация результатов

При использовании полиномиального базиса достаточно высокой степени (n = 8) метод коллокаций должен обеспечивать хорошую аппроксимацию точного решения $y(x) = x^4 + \ln{x}$.

Поскольку точное решение содержит как полиномиальную часть ($x^4$), так и логарифмическую ($\ln{x}$), можно ожидать, что полиномиальная аппроксимация будет хорошо воспроизводить $x^4$, но может иметь погрешность при аппроксимации $\ln{x}$.

### Преимущества метода коллокаций в данной задаче:

1. Получение непрерывного аналитического приближения решения
2. Возможность легко вычислить значение решения в любой точке отрезка
3. Компактное представление решения в виде полинома
