# Решение уравнения колебания струны методом сеток

## Задание

Используя метод сеток, составить решение смешанной задачи для уравнения колебания струны $ \dfrac{\partial^2 u}{\partial t^2} = \dfrac{\partial^2 u}{\partial x^2} $ с начальными условиями $u(x, 0) = f(x) = 0.5x(x+1), u_t' (x, 0) = Ф(x) \cos{x} (0 \leq x \leq 1) $ и краевыми условиями $u(0, t) = \phi(t) = 2t^2, u(1, t) = \psi(t) = 1$. Решение выполнить с шагом $h$ = 0,1, определяя значения функции u(x, t) с четырмьмя десятичными знаками, причем $0 \leq t \leq 0.5$.

## Образец выполнения задания

Для решения задачи используется соотношение:
\[ u_{i,j+1} = u_{i+1,j} + u_{i-1,j} - u_{i,j-1}, \]
где \( i = 1, 2, \ldots \); \( j = 1, 2, \ldots \).

При этом начальные условия задаются как:
- \( u_{i0} = f_i \)
- Для определения \( u_{i1} \) используется соотношение:
  \[ u_{i1} = \frac{1}{2}(f_{i+1} + f_{i-1}) + h\Phi_i, \]
  где \( h \) — шаг по пространству.

Координаты \( x_i \) и \( t_j \) задаются следующим образом:
- \( x_i = 0 + ih \), где \( i = 0, 1, 2, \ldots, n \), \( n = \frac{1 - 0}{h} = 10 \)
- \( t_j = 0 + jh \), где \( j = 0, 1, 2, 3, 4, 5 \)

Граничные условия:
- \( u_{0j} = \varphi(t_j) \)
- \( u_{nj} = \psi(t_j) \)

Решение задачи удобно представить в виде таблицы, которая и является ответом.

### Алгоритм решения

1. Задаем шаги сетки $h = 0.1$ и $\tau = 0.05$
2. Создаем сетку с узлами $(x_i, t_j)$
3. Заполняем начальные условия при $t=0$: $u(x_i, 0) = 0.5 \cdot x_i \cdot (x_i + 1)$
4. Заполняем граничные условия при $x=0$ и $x=1$: $u(0, t_j) = 2t_j^2$ и $u(1, t_j) = 1$
5. Вычисляем значения на первом временном слое, используя начальную скорость
6. Применяем разностную схему для вычисления значений на последующих временных слоях
7. Визуализируем полученное решение


устойчивость численной схемы, что подтверждается отсутствием нефизичных осцилляций в решении.
